# Changelog

All notable changes to the `acode-hermes` plugin will be documented in this file.

## [1.0.0] - 2026-08-12

### Added
- Initial release of Acode Hermes Agent plugin.
- Native integration with Nous Research Hermes Agent (`hermes-agent` v0.19.0).
- Acode Terminal API launcher (`acode.require('terminal')`).
- Shell launcher tools (`hermes`, `hermes-setup`, `hermes-check`, `hermes-repair`, `hermes-update`).
- Integrated Acode Command Palette commands and interactive status dialog UI.
